- 这只是**清单/许可证可见性**，不是完整 SBOM（无 SPDX/CycloneDX、无版本/依赖图哈希）。

- 仅生产依赖（pnpm `--prod`）；devDependencies 不在 npm artifact。
- 不做许可证合规判定/白名单/阻断；artifact 保留期按 GitHub 默认。
